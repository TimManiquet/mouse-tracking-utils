Mouse-tracking toolbox

Preprocess mouse-tracking trial data and turn it into time-resolved distance arrays, with plotting and exclusion tools. It works for any task where a participant clicks a start button, sees a stimulus, and moves to one of n response buttons (2, 4, 8, ...), whatever the stimuli and button layout.

raw CSVs ─► preprocess_mouse_tracking_data ─► exclude_trials / exclude_participants
                         │                                   │
                         └────────────► extract_distance ◄───┘
                                              │
                                      MotorMovementData ─► average / save / load
